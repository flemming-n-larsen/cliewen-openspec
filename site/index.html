cliewen-delivery

Available in the local alpha. Turn an understood change into specified behavior, implementation and evidence.

cliewen-discovery

Planned: investigate the problem, compare alternatives and preserve the decision.

cliewen-all

Planned: combine discovery and delivery in a single coherent workflow.

One shared base

The shared design brings together Decision Records, structured Markdown, Mermaid diagrams, stable acceptance identities and evidence. Plans are optional; existing ticket systems and test tools remain part of the workflow.

What is available today?

The first alpha provides a delivery schema, repository installer, persistent acceptance IDs, a Node test adapter and evidence checks. An integration test exercises the chain through OpenSpec archive. Build a local tarball to try it; no npm release has been published. Discovery/all, update/uninstall and structural documentation validators remain planned.
