With evidence enabled, record sources and actual experiments: command or method, input or revision, observed outcome, and limitations. Label experiments not run and explain why; never invent observations.
Check that the measuring method actually observes the claimed quantity before using its numbers. For example, an interval cannot sample heap during synchronous work that blocks the event loop; verify that samples were taken during the operation.
Distinguish peak memory from retained memory after garbage collection. If a measurement is invalid, report that quantity as unmeasured and revise conclusions that depended on it; an approximate label does not make it valid.
