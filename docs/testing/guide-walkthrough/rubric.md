# Guide walkthrough review criteria

Check actual commands and the resulting project independently of the agent's opinion. Record whether the agent used the guide as supplied, completed archive with fresh evidence, and needed undocumented recovery steps. Review the saved retrospective only after the walkthrough; it must distinguish observed defects, preferences, infrastructure problems, and untested steps.

Verify the requested and observed model, fresh initial session, continuation ID, package/source inputs, process limits, and known context contamination. A resumed retrospective is valid only when it continues this trial's session. A successful CLI exit or a favorable review alone does not establish that the guide works.

This is an agent-assisted first-use exercise. It does not replace a human usability test or broad release evaluation. Raw events may contain local paths and project content; retain them privately and summarize supported findings in a repository report.
